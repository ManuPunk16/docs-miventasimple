# Exportación de Datos y Respaldos

VentaSimple proporciona mecanismos ágiles para extraer la información de tu comercio, tanto para análisis financiero y fiscal como para resguardo histórico y soberanía de datos.

---

## 1. Exportaciones Operativas a Hojas de Cálculo (CSV / Excel)

Desde las distintas secciones operativas puedes generar descargas tabulares listas para abrir en Microsoft Excel, Google Sheets o importar a tu software contable:

- **Catálogo de Productos (`/productos`):** Exporta el inventario completo con nombres, SKU, códigos de barras, categoría, costo, precio de venta y existencias.
- **Historial de Ventas y Tickets (`/reportes/caja` y `/reportes`):** Detalle operación por operación con fecha, cajero, sucursal, método de cobro (Efectivo, Tarjeta, Transferencia, Fiado) e impuestos. Ideal para declaraciones fiscales de RESICO o régimen general.
- **Auditoría de Mermas y Ajustes (`/reportes/inventario`):** Bitácora de pérdidas por caducidad, merma operativa o daño con costo contable desglosado.
- **Liquidación de Comisiones (`/reportes/comisiones-empleado`):** Resumen por colaborador para pago de nóminas o liquidación de honorarios.
