# Inventario y Productos

El módulo de inventario te permite organizar tu catálogo de productos, controlar las existencias en tiempo real y recibir alertas cuando un producto esté por agotarse.

## Conceptos Clave

- **Código de Barras:** Identificador único para el escaneo rápido en caja.
- **Stock Mínimo:** Umbral que define cuándo el sistema te alertará para reabastecer el producto.
- **Categorías:** Agrupaciones lógicas (ej. Bebidas, Alimentos, Electrónicos) para facilitar las búsquedas y reportes de ventas.

## Creación de un Producto

1. Ve a la sección **Productos** en el menú de VentaSimple.
2. Haz clic en **Nuevo Producto**.
3. Rellena los datos requeridos: nombre, precio de compra, precio de venta, y existencias.
4. Presiona **Guardar**.
