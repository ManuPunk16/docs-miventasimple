# Barberías y Salones de Belleza

Gestiona el flujo de cortes, tintes y tratamientos asignando colaboradores a cada servicio y calculando comisiones transparentes sin errores.

## 1. Asignación de Barbero en Caja

Cada vez que se atiende a un cliente en el sillón:
1. Agrega el servicio del catálogo (ej. *Corte Clásico*, *Perfilado de Barba*).
2. Asigna el especialista que realizó el trabajo.
3. El sistema asocia el porcentaje o monto fijo de comisión configurado para ese empleado.

:::note[Comisiones Claras]
Al final de la jornada o semana, el reporte de comisiones desglosa el total acumulado por barbero para liquidaciones inmediatas.
:::

## 2. Venta Cruzada de Productos para Cuidado Personal

Si el cliente adquiere cera, aceite para barba o shampoo:
- Se agregan al mismo ticket de cobro.
- Puedes configurar si los productos generan comisión o ingresan íntegros al negocio.
