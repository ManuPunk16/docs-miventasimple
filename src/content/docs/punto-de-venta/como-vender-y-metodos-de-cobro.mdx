## Cómo realizar una venta

Para realizar una venta en VentaSimple:
1. Agrega productos al carrito mediante el buscador o escaneando su código de barras.
2. Toca el botón **Cobrar**.
3. Elige el método de pago (Efectivo, Tarjeta, o Fiado).
4. Confirma la operación y genera el ticket.
